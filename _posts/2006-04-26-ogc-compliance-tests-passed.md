The GeoServer Project is pleased to announce that we have successfully completed the [OGC](http://www.opengeospatial.org) certification tests for WFS 1.0 and WMS 1.1.1 compliance with [GeoServer 1.3](https://web.archive.org/web/20060510143735/http://docs.codehaus.org/display/GEOS/Stable). GeoServer is the only open source server to have passed both test suites, and GeoServer is also the Reference Implementation for the WFS 1.0 specification. There are PostGIS configurations with the test data so that any one can replicate our results, and in addition all GeoServer's are 'standard by default', meaning in setting up a layer you are guaranteed to be following the standards, while other servers require additional configuration.
