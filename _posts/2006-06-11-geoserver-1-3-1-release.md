The GeoServer team is proud to announce the official 1.3.1 release. This release contains an upgrade to GeoTools 2.2.x for rendering speed improvements, a new online SLD editor, and a very exciting addition to WMS output: KML/KMZ for Google Earth, including streaming data, user rendering choices and easy network links. For read more about the KML/KMZ support, head over to the [documentation](https://web.archive.org/web/20060613084505/http://docs.codehaus.org/display/GEOSDOC/Google+Earth).

#### DataStore Extensions

The extensions have not yet been updated, soon we will have plug-ins built for ArcSDE, DB2, VPF, MySQL, ect. Apologies for not having them ready yet, but we wanted to get something out soon. If you want to get going earlier, you can download the latest [GeoTools 2.2](https://web.archive.org/web/20060611/http://docs.codehaus.org/display/GEOTOOLS/Downloads) release, and plug-in the built jars to GeoServer.
