GeoServer 1.4.0-RC5 has been released, check it out below.

----

The GeoServer 1.4.0-RC5 beta release is available for download from the [SourceForge Download Page](https://sourceforge.net/projects/geoserver/files/GeoServer/1.4.0-RC5/):

#### Deployment

- [geoserver-1.4.0-RC5-war.zip](https://sourceforge.net/projects/geoserver/files/GeoServer/1.4.0-RC5/geoserver-1.4.0-RC5-war.zip/download)
- [geoserver-1.4.0-RC5-bin.zip](https://sourceforge.net/projects/geoserver/files/GeoServer/1.4.0-RC5/geoserver-1.4.0-RC5-bin.zip/download)

#### Windows Installer

- [geoserver-1.4.0-RC5.exe](https://sourceforge.net/projects/geoserver/files/GeoServer/1.4.0-RC5/geoserver-1.4.0-RC5.exe/download)

#### Source Code

- [geoserver-1.4.0-RC5-src.zip](https://sourceforge.net/projects/geoserver/files/GeoServer/1.4.0-RC5/geoserver-1.4.0-RC5-src.zip/download)

#### Extra Plugins

- Server-side [Caching](https://web.archive.org/web/20061207/http://docs.codehaus.org/display/GEOSDOC/Caching). Especially useful for tiling clients such as OpenLayers or Google Maps.
- [Windows Service Wrapper](https://web.archive.org/web/20061207/http://docs.codehaus.org/display/GEOSDOC/Windows+Service+Wrapper): Run GeoServer as a service.

Tested with: JBoss, Jetty, Tomcat, WebLogic
