The GeoServer community is happy to announce the release of GeoServer 2.5.4, now available for [download](http://geoserver.org/release/2.5.4). This is the latest maintenance release for the GeoServer 2.5.4 series. Check out the [change log](#release-notes) for more details.

Happy holidays and thanks for using GeoServer!

## Release notes

Improvement:

* [GEOS-6603](https://osgeo-org.atlassian.net/browse/GEOS-6603) Add a button for disabling native warp
* [GEOS-6800](https://osgeo-org.atlassian.net/browse/GEOS-6800) sldservice: improvements to docs, tests and some bugfixes

Bug:

* [GEOS-6426](https://osgeo-org.atlassian.net/browse/GEOS-6426) Administration UI does not work properly with Internet Explorer 11
* [GEOS-6573](https://osgeo-org.atlassian.net/browse/GEOS-6573) `<Priority>` tag not processed by SLD1.1 engine
* [GEOS-6687](https://osgeo-org.atlassian.net/browse/GEOS-6687) INSPIRE extension misses the icelandic language
* [GEOS-6748](https://osgeo-org.atlassian.net/browse/GEOS-6748) PointPlacement with Rotation in TextSymbolizer gives NullPointerException
* [GEOS-6751](https://osgeo-org.atlassian.net/browse/GEOS-6751) WFS can OOM when gzipping large compressible output
